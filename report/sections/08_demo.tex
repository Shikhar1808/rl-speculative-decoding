\section{Live demo}

The centrepiece of the presentation is a live race (\texttt{uv run python -m specrl.app}): the same prompt is
generated by the target model alone and by the target plus an RL agent, shown side by side with a live
tokens-per-second counter. It uses the SmolLM2 pair, where the size gap between draft and target is largest.

\begin{itemize}
  \item \textbf{Coloured tokens:} green = accepted draft token, red struck-through = rejected draft, bold =
  the target's own token, and a thin bar wherever the agent pressed \STOP{}. Hovering a token shows the
  draft's confidence.
  \item \textbf{Confidence meter:} the draft confidences of the latest round next to the agent's decision.
  \item \textbf{Policy selector:} any of the four agents or the two baselines, so the audience can compare
  them on their own prompt.
\end{itemize}

Both generations run one after the other on the GPU and every token is timestamped as it is produced; the
two panes then replay at the recorded speed. Running both at the same time would make them share the GPU and
slow each other down, so the race would not be fair. The speedup shown is the measured one.
